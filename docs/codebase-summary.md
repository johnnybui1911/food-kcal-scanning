# Codebase summary

Navigation only. Open the linked owner for behavior.

## Entry points


| Concern                                        | Owner                                                                                       |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------- |
| App routes (onboarding, scan, result, history) | [`src/app/`](../src/app/) — file-based routes via Expo Router; root layout in `_layout.tsx` |
| Worker entry and API routing                   | [`worker/index.ts`](../worker/index.ts)                                                     |
| Worker bindings, vars, quotas config           | [`wrangler.jsonc`](../wrangler.jsonc)                                                       |
| Expo app config                                | [`app.json`](../app.json)                                                                   |
| PWA shell (manifest, Apple meta tags, icons)   | [`public/`](../public/)                                                                     |
| Release pipeline                               | [`scripts/release.sh`](../scripts/release.sh)                                               |
| API smoke test                                 | [`scripts/smoke-api.sh`](../scripts/smoke-api.sh)                                           |

## Tests

Unit tests live next to their module area in `__tests__/` folders; the include
globs are in [`vitest.config.mts`](../vitest.config.mts).

## Generated or local-only files

- `worker-configuration.d.ts` — Worker `Env` types, generated by `npx wrangler types`; gitignored.
- `dist/` — web export output; gitignored.
- `.dev.vars` — local Worker secrets; gitignored.
- `scripts/fixtures/food*.jpg` — the real food photo used by the smoke test; gitignored.
